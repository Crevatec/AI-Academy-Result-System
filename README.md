# AI-Based Academic Result Management & Performance Prediction System

## Project Title
Design and Implementation of an AI-Based Academic Result Management and Performance Prediction System with Automated GPA/CGPA Computation for Higher Institution

---

## Tech Stack & Why Each Was Chosen

| Layer | Technology | Reason |
|---|---|---|
| Backend Framework | Flask (Python) | Lightweight, easy to structure as API, great for academic projects, integrates natively with Scikit-learn |
| Database | SQLite (dev) / PostgreSQL (prod) | SQLite = zero config for local testing; PostgreSQL = production-grade, used by universities worldwide |
| ORM | SQLAlchemy | Prevents SQL injection, handles migrations, works with both SQLite and PostgreSQL |
| AI/ML | Scikit-learn | Industry standard, simple enough to explain in HND project, supports Logistic Regression, Decision Tree, Random Forest |
| Email | Flask-Mail + SMTP | Works with Gmail or institutional SMTP; no paid service needed for testing |
| Password Security | bcrypt (via Flask-Bcrypt) | Industry standard hashing; plain MD5/SHA1 is unacceptable |
| Frontend | Jinja2 HTML Templates + Vanilla JS | No build tools needed, renders server-side, works on any device |
| Charts | Chart.js (CDN) | Lightweight, no npm needed, renders GPA trend charts in browser |
| Excel Upload | openpyxl | Pure Python, reads .xlsx files for bulk score upload |
| Auth | Flask-Login + Flask-WTF (CSRF) | Session management + form protection |
| Migration | Flask-Migrate (Alembic) | Tracks database schema changes safely |
| Environment Config | python-dotenv | Keeps secrets out of source code |
| Testing | pytest | Standard Python testing framework |

## Local Setup (Step by Step)

### 1. Prerequisites
- Python 3.10+
- pip
- Git

### 2. Clone and enter project
```bash
git clone <your-repo-url>
cd acadresult/backend
```

### 3. Create virtual environment
```bash
python -m venv venv
source venv/bin/activate        # Mac/Linux
venv\Scripts\activate           # Windows
```

### 4. Install dependencies
```bash
pip install -r requirements.txt
```

### 5. Set up environment variables
```bash
cp ../config/.env.example .env
# Edit .env with your values
```

### 6. Initialize the database
```bash
flask db init
flask db migrate -m "initial"
flask db upgrade
python ../scripts/seed_db.py
```

### 7. Train the AI model
```bash
python app/ai/train.py
```

### 8. Run the development server
```bash
python run.py
```
Open browser: http://localhost:5000
